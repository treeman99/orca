# 승격 후보

코디네이터가 `worker_done` 이후 사용자 지적을 받으면 여기에 **한 건씩** 자동으로 적는다. 승인은
필요 없다 — 이 파일은 어떤 워커의 컨텍스트에도 들어가지 않으므로 틀린 후보가 쌓여도 실행 비용이 0이다.

승격은 사람이 결정한다. **관측 2회** 이상이거나 사용자가 명시적으로 요청했을 때만 `rules.md` 승격을
제안하고, 다음 중 하나에 해당하면 제안하지 않는다.

- `pnpm lint` / `pnpm typecheck`가 이미 잡는다 → 기각
- 기존 블록과 `scope`가 겹친다 → 병합안으로 제시
- 이 머신에서만 참인 사실이다 → 세션 메모리로 보내고 커밋하지 않는다

형식은 아래와 같다. 요약이 아니라 **다음 워커가 실행할 지시**로 쓴다.

```
### C-00N · scope: <scope> · 관측 N회 · YYYY-MM-DD
<다음 워커가 해야 할 일 한 문단>
출처: <task_id> worker_done 직후 사용자 지적
```
